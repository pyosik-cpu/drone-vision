# 装甲板识别串口文本格式

串口参数为115200、8N1、无硬件流控。状态机确认主目标后，每帧发送一行：

```text
x_m,y_m,z_m,center_x_px,center_y_px
```

示例：

```text
0.0000,0.0000,0.0000,1032.50,487.25
```

- `x_m,y_m,z_m` 是相机坐标系坐标，单位为米。
- `center_x_px,center_y_px` 是原始传感器图像中的装甲板中心像素坐标。
- 当前PnP后端尚未启用，所以XYZ固定输出为0；只能使用中心像素坐标。
- 没有经过状态机确认的目标时不发送数据。

这是方便当前调试的纯文本格式，没有包头和CRC，不建议直接作为最终上车协议。
